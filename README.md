# JAZZ AI Command Center

Kimmy's private, mobile-first and Parkinson-friendly AI Chief of Staff interface.

## Included

- Central Jazz orb with slow status orbit
- 11 deployable specialist agents and permanent Kimara node
- Large one-tap actions, STOP control and Reduce Motion mode
- Natural browser voice greeting
- Live Work activity log with honest connection status
- Approval and Google Connections screens
- Local playback for Kimmy's legally provided music file
- Permanent System Builder with quick-start system types, voice idea capture, approval gates, honest Live Work stages and device-local My Systems memory
- Permanent Kimara Brand Identity Vault with approved colors, personality, wardrobe, content rules, identity lock, approval-gated changes and private device-only Master Face storage

## Important

This GitHub Pages interface never invents Gmail, Drive or Calendar data. Secure Google OAuth and a protected backend must be connected before those services can perform real actions.

The System Builder plans, approves and remembers system requests in the browser. Autonomous repository creation, backend/database work and deployment require a connected protected build service; unfinished stages are shown as pending rather than falsely reported as complete.

Kimara's written brand rules are versioned with Jazz AI. Her uploaded Master Face is deliberately kept in private browser storage on Kimmy's device and is never committed to this public repository.

## Publish

In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.
