# JAZZ AI Command Center

Kimmy's private, mobile-first and Parkinson-friendly AI Chief of Staff interface.

## Included

- Central Jazz orb with slow status orbit
- 11 deployable specialist agents and permanent Kimara node
- Large one-tap actions, STOP control and Reduce Motion mode
- Natural browser voice greeting
- Live Work activity log with honest connection status
- Approval and Google Connections screens
- Local playback for Kimmy's legally provided music file

## Important

This GitHub Pages interface never invents Gmail, Drive or Calendar data. Secure Google OAuth and a protected backend must be connected before those services can perform real actions.

## Publish

In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.
